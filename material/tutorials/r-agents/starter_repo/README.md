# Week 6: Prompting and AI agents

This starter project supports the four exercises in the Week 6 tutorial. The Canvas download bundle includes both this project and the course SQLite database. It also includes a small synthetic CSV for the prompting exercise.

## Open the project

Download and unzip the single Week 6 bundle from Canvas. It includes:

```text
data/tiktok_students.sqlite
```

Open this folder in Positron or your preferred editor. Run commands from the project root so relative paths work. Install Quarto and the R packages used in the exercises if they are not already available:

```r
install.packages(c("DBI", "RSQLite", "readr", "dplyr", "ggplot2", "knitr"))
```

Configure Tilly and OpenCode using the instructor's setup instructions. Keep any API key outside this folder; never add credentials to prompts or Git.

## Project files and exercise outputs

```text
data/
  sample_video_view.csv        # synthetic data for Exercise 1
  tiktok_students.sqlite       # included in the Canvas bundle; do not commit
  exports/                     # CSVs generated in Exercise 3
  analysis/                    # summary generated in Exercise 4
src/
  export_table.R               # complete with an agent in Exercise 3
  build_creator_summary.R      # prepares the report input
report.qmd                     # report generated by the Makefile
output/                        # generated report
```

In Exercise 3, complete and run `src/export_table.R` once for each requested table:

```bash
Rscript src/export_table.R video_view
Rscript src/export_table.R creators
```

The script should create `data/exports/video_view.csv` and `data/exports/creators.csv`. In Exercise 4, an agent will create a small Makefile to connect the export, summary, and report stages. **There is no Makefile in the starter project.**

Generated CSVs, the bundled database, and the rendered report are ignored by Git. Commit source code and documentation, not generated outputs or credentials.
