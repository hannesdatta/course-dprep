# Data Preparation and Programming Skills (dPrep)

[![DOI](https://zenodo.org/badge/292224306.svg)](https://zenodo.org/badge/latestdoi/292224306)

This repository provides public access to the educational materials, tutorials, and source code for **Data Preparation and Programming Skills (dPrep)**, a course in the Marketing Analytics curriculum at [Tilburg University](https://tilburguniversity.edu), taught by [Dr. Hannes Datta](https://hannesdatta.com).

The **main version of the course is hosted on Canvas at Tilburg University**, while this repository serves as a public resource for self-learners and contributors.

**If you are looking for the previous edition of the course (last taught in spring 2024/2025), you can find it [archived on Zenodo](https://doi.org/10.5281/zenodo.16925070).**

## About the Course

This course equips students with essential skills in **data preparation, programming, and automation** to address real-world data challenges. Topics include:
- Version control with Git
- Data wrangling and visualization in R
- Workflow automation with Make
- Cloud computing and storage
- Reproducible research practices

## Repository Contents

This repository contains:
- **Syllabus (`syllabus/`)**: The formal course syllabus, which can be copied into Canvas if needed
- **Course Materials (`material/`)**: Slides and tutorials with hands-on exercises for Git, R, Make, and more
- **Book (`book/`)**: An accompanying book, *Data Preparation and Programming Skills*, is available at [dprep-book.hannesdatta.com](https://dprep-book.hannesdatta.com). It provides a structured guide to course topics, including practical examples and theoretical foundations
- **TikTok Data (`tiktok-data/`)**: Simulated TikTok data used for the student project
- **App (`app/`)**: An interactive app with pre-class exercises (for example, a dummy terminal and a dummy R session), similar to DataCamp and available only in the browser

You are welcome to explore, use, and contribute to these materials.
